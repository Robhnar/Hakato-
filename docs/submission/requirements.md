# Submission requirements — NASA Space Apps Challenge 2026

Recorded 2026-11-14 from the official event page, the participant FAQ and the NASA Space Apps Project Submission Guide / discussions. Before submitting, **verify again** at https://www.spaceappschallenge.org/resources/project-submission-guide/ (the page gets updated during the weekend).

## Deadlines

| What | When |
| --- | --- |
| Project editing opens | Saturday **2026-11-14**, 09:00 local time of the team owner's event |
| Global deadline | Sunday **2026-11-15**, **23:59** local time of the team owner's event |
| Local events | may have an earlier cutoff for local judging — check with your Local Event |

The time zone is set by the team owner's Local Event, not by the location of individual members.

## Where to submit

1. Log in at https://www.spaceappschallenge.org/
2. Go to the team page → **Project** tab → **Edit**
3. Fill in the fields (in English), tick the confirmations, **Submit**
4. You can edit and resubmit until the deadline

## Demo format (mandatory)

Exactly one of:

- **video ≤ 30 seconds**, or
- **presentation ≤ 7 slides** (including the title and closing slides)

A link in the Project Demo field (e.g. YouTube Unlisted / Google Drive / slides PDF). Longer materials may be added — they do not replace the short demo.

## Form fields (EN)

Based on local guides and the 2026 FAQ — field names may differ slightly on the site:

| Field | Content |
| --- | --- |
| Project Name | Short product name |
| High-Level Summary | A few sentences: problem, solution, significance |
| Project Demo | Link to a ≤30 s video or ≤7 slides |
| Final Project | Link to the product (repo / running app) |
| Project Details | How it works, stack, benefits, team goals |
| Use of Artificial Intelligence | Which AI tools and for what; or "No AI used" |
| NASA / Partner Data | At least **one** NASA dataset from the challenge Resources + how it was used |
| References | Libraries, data, images, articles, AI |

AI is allowed in 2026; its use must be disclosed. AI-generated images/video require a visible watermark.

## Global Awards criteria (short)

The project must **actually use** at least one NASA source from the chosen challenge's Resources tab (quoting facts is not enough). Our challenge: *Lunar Landing Site Navigator*.
