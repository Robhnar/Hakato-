# Wymagania zgłoszenia — NASA Space Apps Challenge 2026

Spisane 2026-11-14 na podstawie oficjalnej strony wydarzenia, FAQ uczestników oraz Project Submission Guide / dyskusji NASA Space Apps. Przed wysłaniem **ponów weryfikację** na https://www.spaceappschallenge.org/resources/project-submission-guide/ (strona bywa aktualizowana w trakcie weekendu).

## Terminy

| Co | Kiedy |
| --- | --- |
| Otwarcie edycji projektu | sobota **2026-11-14**, 09:00 czasu lokalnego wydarzenia właściciela zespołu |
| Deadline globalny | niedziela **2026-11-15**, **23:59** czasu lokalnego wydarzenia właściciela zespołu |
| Lokalne wydarzenia | mogą mieć wcześniejszy cutoff na ocenę lokalną — sprawdź u swojego Local Event |

Strefę czasową ustala Local Event właściciela zespołu (Team Owner), nie lokalizacja poszczególnych członków.

## Gdzie wysłać

1. Zaloguj się na https://www.spaceappschallenge.org/
2. Wejdź na stronę zespołu → zakładka **Project** → **Edit**
3. Wypełnij pola (po angielsku), zaznacz potwierdzenia, **Submit**
4. Można poprawiać i wysyłać ponownie do deadline’u

## Format demo (obowiązkowy)

Dokładnie jedno z:

- **wideo ≤ 30 sekund**, albo
- **prezentacja ≤ 7 slajdów** (w tym tytułowy i końcowy)

Link w polu Project Demo (np. YouTube Unlisted / Google Drive / PDF slajdów). Dłuższe materiały mogą być dodatkowe — nie zastępują krótkiego demo.

## Pola formularza (EN)

Na podstawie przewodników lokalnych i FAQ 2026 — nazwy pól mogą lekko się różnić na stronie:

| Pole | Treść |
| --- | --- |
| Project Name | Krótka nazwa produktu |
| High-Level Summary | Kilka zdań: problem, rozwiązanie, znaczenie |
| Project Demo | Link do ≤30 s wideo lub ≤7 slajdów |
| Final Project | Link do produktu (repo / działająca aplikacja) |
| Project Details | Jak działa, stack, korzyści, cele zespołu |
| Use of Artificial Intelligence / SI | Jakie narzędzia AI i do czego; albo „No AI used” |
| NASA / Partner Data | Co najmniej **jeden** zestaw danych NASA z Resources wyzwania + jak użyty |
| References | Biblioteki, dane, obrazy, artykuły, AI |

AI jest dozwolone w 2026; użycie trzeba ujawnić. Dla AI-generowanych obrazów/wideo wymagany jest widoczny watermark.

## Kryteria Global Awards (skrót)

Projekt musi **rzeczywiście korzystać** z co najmniej jednego źródła NASA z zakładki Resources wybranego wyzwania (nie wystarczy cytat faktów). Nasze wyzwanie: *Lunar Landing Site Navigator*.
